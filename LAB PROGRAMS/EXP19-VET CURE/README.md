# VetCure Frontend Prototype

A responsive veterinary healthcare management frontend built with plain HTML, CSS and JavaScript.

## Included
- Farmer registration and login
- Doctor registration and login
- Farmer dashboard
- Post animal complaint
- Image/audio/video file selection
- Complaint status and doctor response
- Doctor dashboard
- Cure/disease management
- News management
- Doctor/user/payment/feedback views
- Government CVH free consultation model
- Private doctor fee model
- Bank transfer and EasyPaisa payment information
- Feedback
- Disease-area report based on stored complaint records
- LocalStorage persistence
- Smooth page transitions, hover effects, floating hero animation and responsive design

## Run
Open `index.html` directly in a browser, or serve the folder with a simple local server.

## Important
This is a frontend prototype. LocalStorage is NOT a secure production database, passwords are intentionally stored only for demonstration, and payment records are simulated. A production system should use a backend, hashed passwords, secure authentication, object storage for media, database transactions, and a real payment gateway.
