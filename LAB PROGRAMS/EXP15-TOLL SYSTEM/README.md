# EasyToll Website

## Files
- `index.html` — complete website containing HTML, CSS, and JavaScript.

## Run
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, or Firefox.

## Notes
- This is a front-end demonstration. Data is saved in browser `localStorage`.
- Login credentials are not securely stored; do not use real passwords.
- Wallet top-ups are simulated. No real payments are processed.
- The QR graphic is illustrative, not a production scannable QR code.
- Admin and Toll Gate roles are demo role selectors, not secure authorization.
