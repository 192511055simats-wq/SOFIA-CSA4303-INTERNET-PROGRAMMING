HOMEFINDER — FRONT-END INTERNET PROGRAMMING LAB PROJECT

Files:
- index.html: website structure
- style.css: green shades, responsive layout, transitions and animations
- script.js: sample listings and interactive features

Run:
1. Extract the ZIP.
2. Open index.html in a browser, or open the folder in VS Code and use Live Server.

Features:
- Search by location, property type and maximum budget
- Saves search preferences in browser localStorage
- Demo buyer sign-in/register
- Save and remove favourite properties
- Book viewing requests and save visitor records locally
- Google Maps search links for property locations
- Agent contact links
- Responsive design and animated transitions

Note: This is a front-end educational demo with sample property data. It has no backend/database. localStorage is browser-only and is not secure for real passwords or sensitive customer information. Production authentication and permanent records require a backend and database.
